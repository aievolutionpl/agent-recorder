# Roadmap

## MVP — teraz

- loopback receiver na losowym porcie;
- JSONL per session w `userData`;
- token opcjonalny, redakcja sekretów, brak chain-of-thought;
- React Agent Session panel z filtrami i live subscription;
- testy protokołu, serwera i komponentu.

## Następne kroki

- integracje instalowane z CLI (Codex, Claude Code, browser runners);
- wybór aktywnej sesji i ręczny import/eksport z panelu;
- snapshoty osi wraz z nagraniem i markerami w timeline;
- rotacja/retencja lokalnych JSONL oraz diagnostyka receivera;
- opcjonalne, jawnie włączane udostępnianie sesji.
