# Agent Recorder — Product

## Cel

Windows-first recorder dla pracy agentów AI: nagrywa ekran, a obok daje lokalny, bezpieczny zapis zdarzeń narzędziowych do późniejszego odtworzenia i analizy.

## Odbiorcy

Developerzy, maintainers i zespoły QA budujące integracje z agentami CLI, browser automation i narzędziami developerskimi.

## Zasady

1. Local-first: loopback i pliki użytkownika jako domyślna granica danych.
2. Privacy-by-default: redakcja sekretów, brak chain-of-thought.
3. Observable, not intrusive: panel ma pomagać, ale nie może naruszać działającego nagrywania.
4. Windows-first, cross-platform aware: Node built-ins i bezpieczne ścieżki Windows.
